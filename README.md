Campus Shield

A Campus Safety and Emergency Incident Reporting System

1. Project Overview

Campus Shield is a campus safety platform designed to help students report emergencies and safety incidents and help authorized campus security personnel manage and respond to those reports.

2. Problem Statement

Students may face difficulty reporting campus safety concerns and receiving timely updates about their reports. Campus Shield aims to provide a centralized platform for incident reporting, emergency alerts, and response tracking.

3. Project Objectives

- Provide a simple interface for reporting campus incidents.
- Enable students to submit emergency alerts.
- Help authorized security personnel review and manage reports.
- Track incident status from submission to resolution.
- Maintain incident records for authorized users.

4. Main Modules

1. User Authentication and Access Control
2. Student Dashboard
3. Emergency SOS
4. Incident Reporting
5. Location Management
6. Security and Admin Dashboard
7. Incident Tracking
8. Notifications
9. Incident History and Database Management

5. Proposed Architecture

- Frontend: Student and security interfaces.
- Backend: Request processing, incident management, and access control.
- Database: User accounts, incident reports, locations, and status records.
- Notifications: Updates for relevant users and authorized security personnel.

The final technology stack and detailed design will be confirmed before implementation.
